## 🔴 第一优先级

### 1. 药物相互作用库严重不足 —— ✅ 已完成（数据驱动自动推导）

**原问题**：只有 22 对硬编码，临床有意义组合至少 200+ 对。

**采用方案**（你的原方案）：转为从 `drugs.json` 数据自动推导，无需逐对硬编码。

**实现**：
- 每味药新增 `rx` 药理标签字段：
  - `sub/inh/ind` — CYP 底物 / 抑制 / 诱导（1A2、2C19、2C9、2D6、3A4、2B6、2E1）
  - `serot` 5-HT 能强度、`cns` 镇静强度、`qt` QT 风险、`seiz` 癫痫阈值
  - `ach` 抗胆碱、`hypo` 体位性低血压、`opio` 阿片、`maoi` MAOI
  - `other` 特殊标签（`lithium`、`agranulocytosis`、`opioid_antagonist`、`bzd` 等）
- 前端 `deriveInteractions()` 规则引擎，11 类规则自动生成结论
- `getInteraction()` 合并「人工精调 PAIRS」+「自动推导」，取最高危等级

**效果**：

| 指标 | 数值 |
|---|---|
| 覆盖组合 | 1891 对全组合 |
| 推导出相互作用 | **1048 对（55.4%）** |
| 等级分布 | 禁忌 14 / 严重 433 / 中等 994 |
| 对比原 72 对硬编码 | **覆盖提升约 14 倍** |

新增药物自动纳入规则，**无需再手工维护逐对数据**。
已覆盖：5-HT 综合征、MAOI 禁忌、阿片拮抗致急性戒断、CYP 抑制/诱导、QT 叠加、
呼吸抑制、癫痫阈值、抗胆碱叠加、锂盐窄治疗窗、氯氮平血液学监测。
